# PageTiler for Moodle — public issue tracker

This repository is the **public bug and support tracker** for **PageTiler** (`mod_pagetiler`).

Plugin **source code is not published here**. Purchase and download PageTiler from Moodle Marketplace (includes free Site pages).

## Related

| Plugin | Tracker |

## Demo and docs

- Demo: https://pagetiler.ivent.pl
- Admin guide: https://pagetiler.ivent.pl/local/sitepages/view.php?slug=docs

## How to report an issue

1. Open a [new issue](https://github.com/noutero/pagetiler-moodle-tracker/issues/new/choose).
2. Include Moodle version, theme, and steps to reproduce.

## Security

Please do **not** open public issues for security vulnerabilities. Contact the author via the Marketplace listing support channel.

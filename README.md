# PageTiler for Moodle — public issue tracker

This repository is the **public bug and support tracker** for:

| Plugin | Component | Marketplace |
|--------|-----------|-------------|
| **PageTiler** | `mod_pagetiler` | Paid on [Moodle Marketplace](https://moodle.com/products/) |
| **Site pages** | `local_sitepages` | Free companion (included with PageTiler) |

Plugin **source code is not published here**. Purchase and download PageTiler (and the free Site pages ZIP) from Moodle Marketplace.

## Demo and docs

- Demo: [https://pagetiler.ivent.pl](https://pagetiler.ivent.pl)
- Admin guide: [https://pagetiler.ivent.pl/local/sitepages/view.php?slug=docs](https://pagetiler.ivent.pl/local/sitepages/view.php?slug=docs)

## How to report an issue

1. Open a [new issue](https://github.com/noutero/pagetiler-moodle-tracker/issues/new/choose).
2. Mention the plugin in the title or body:
   - `mod_pagetiler` — PageTiler builder / course activity
   - `local_sitepages` — Site pages / homepage / pretty URLs
3. Include Moodle version, theme, and steps to reproduce.

## Security

Please do **not** open public issues for security vulnerabilities. Contact the author via the Marketplace listing support channel.
